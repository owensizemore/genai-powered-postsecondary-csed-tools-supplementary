# GenAI-Powered Postsecondary Computer Science Education Tools: A Systematic Literature Review
Owen Sizemore, Seth Bernstein, Audrey Ostrom, Thomas Rexin, Kristin Stephens-Martinez

## Contents
1. `codebook.csv`: Code categories, short names, definitions, and examples for each of the 46 codes applied to the included papers.
2. `includedpapers.csv`: Full coding of each included paper. Columns are code short names, with a `1` meaning the code was present in the paper and a `0` meaning the code was not present in the paper.
3. `searchstrings.csv`: Exact search strings used in each of the four digital libraries searched.
